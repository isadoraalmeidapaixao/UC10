UC10: Programar aplicação web com integração em servidores de banco de dados
CARGA HORÁRIA: 108 HORAS

Indicadores
Configura o ambiente de desenvolvimento conforme as funcionalidades e características da aplicação para internet a ser codificado.
Desenvolve código utilizando linguagem de programação para back-end de acordo com os requisitos da aplicação para internet e projeto.
Elabora código para acesso a banco de dados conforme as funcionalidades e características do aplicativo.
Integra interfaces de usuário de front-end com estruturas de código back-end de acordo com as funcionalidades da aplicação para internet.
Integra soluções de segurança de dados em estruturas de código back-end de acordo com normas e boas práticas de segurança da informação.
Implementa autenticação e permissãoes de usuário no servidor web de acordo com a linguagem de programação back-end.
Realiza a depuração verificando erros e corrigindo-os de acordo com premissas das linguagens de programação back-end.
Documenta o desenvolvimento da aplicação para internet considerando manutenções do sistema.
